🏠 홈

자동 히어로 + 다음 여행 + 명인소 + 여행스케치 + 플레이리스트 큐레이션

🚆 여행

  • 다가오는 / 박물관 / 후기 — 3 서브탭
  • ← 여행 가는날, 해외문화탐방, 일본 여행, 집밥 아카데미, 여행후기

📖 여행스케치

  • 길 위의 인문학 / 능파의 글 / 여행 편지 / 한줄 / 음악·영상 / 사진 / 도랑가제
  • ← 길위의 인문학, 임상수(능파), 당신은 술보다, 여행! 편지!, 한줄메모, 음악 동영상, 사진, 도랑가제, 숲으로간 미술관

📍 명인소

  • 명인 추천 / 명품 맛집 / 칼국수로드 / 산책 / 지도
  • ← 명인 추천, 명품 맛집!, 칼국수로드, 산책!!

👤 마이

  • 프로필 / 신청 / 카톡 / 검색 / 공지 / 가입
  • ← 명인방공지, 회원가입, 일반 게시판

⚙️ 자동 히어로 (구현 완료)

  • data/tours.json만 편집 = 자동 갱신
  • 오늘 이후 가장 빠른 일정 자동 픽
  • 토글 AUTO_HERO = true로 활성화
  • 현재: OFF (정선 단풍 곤도라 수동 고정)
