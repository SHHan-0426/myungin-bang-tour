# 명인방투어 업데이트 운영 방식 — 하이브리드

발견성·최신성은 **매일 자동**, 품질·판단은 **주 1회 사람(또는 Claude) 큐레이션**으로 나눈 방식입니다.

---

## 큰 그림

| 층 | 주기 | 담당 | 하는 일 |
|----|------|------|---------|
| 자동 수집 | **매주 일요일 22:00 KST** (추후 매일 전환) | GitHub Actions (무인) | 카페 11개 게시판 새 글 수집 → `data/*.json` → 대문 게시판·다가오는 일정에 자동 반영 |
| 큐레이션 | **주 1회** | 운영팀 / Claude | 자동이 못 하는 '판단' — featured 여행·이미지·제목 다듬기·정치 재확인·제안 게시판 관리 |

---

## 1) 자동(매일) — 무인

- **워크플로**: `.github/workflows/sync-cafe.yml` (cron `0 13 * * 0` = 매주 일요일 22시 KST · 매일로 전환 시 `0 13 * * *`)
- **스크립트**: `scripts/sync-cafe.js` (모바일 `m.cafe.daum.net` 방식, 로그인 없이 공개 게시판 수집)
- **하는 일**
  - 새 글 메타(제목·pid·작성일·조회·댓글) 수집
  - **정치·선거 글 자동 제외**(POLITICS 블록리스트 — 여행 글 오탐 방지)
  - `data/*.json`에 새 글만 추가 → 커밋·푸시 → Netlify 자동 배포
- **결과가 보이는 곳**
  - 대문 **'명인방 게시판'** (탭별 새 글 자동 노출)
  - **'다가오는 일정'** (제목의 날짜를 읽어 미래 여행 자동 병합)
  - 상단 '다음 여행' 띠 (가까운 3건 자동 갱신)

> 자동 층은 **원시 데이터**만 다룹니다. 제목은 원문 그대로, 대표 이미지는 수집하지 않습니다 — 그건 아래 큐레이션의 몫.

## 2) 큐레이션(주 1회) — 사람 / Claude 체크리스트

"지난주 카페 정리해줘" 한 마디면 Claude가 아래를 함께 처리합니다.

1. **featured 여행 선정** — 히어로·'다음 여행' 카드에 올릴 대표 여행 고르기 + 다음 CDN 대표 이미지 넣기
2. **제목 다듬기** — `2026 9월1화~4금/홋가이도…` → `홋카이도 토마무 리조트 — 2026 9월 1(화)~4(금)`
3. **정치 필터 재확인** — 자동이 놓친 시사·선거 글 있으면 `data/*.json`에서 제거
4. **후기·스케치 대표글 점검** — 대문 노출 글이 적절한지
5. **개선 제안 게시판(Supabase) 관리** — `status`(접수→검토중→반영) 갱신, 스팸·부적절 글 삭제 (Table Editor)

## 왜 하이브리드인가

- **완전 자동만** → 정치 오탐/누락·투박한 제목·대표 이미지 부재로 품질 저하
- **완전 수동만** → 매주 손이 많이 감, 놓치기 쉬움
- **하이브리드** → 매일 자동으로 신선하게 채우고, 주 1회 사람이 품질만 손봄 = 비용/품질 균형 최적
